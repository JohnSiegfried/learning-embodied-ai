# 1.3 位姿与坐标变换最小集

## 一句话

机器人几何的全部数学 = **用旋转矩阵描述朝向、用齐次变换矩阵描述"位置+朝向"，用链式乘法把关节角换算成末端位姿（FK），再反着解出关节角（IK）**——这一课只取你能读懂 VLA 论文所需的那个最小子集。

## 核心公式/原理

### 1. 位姿（Pose）的严格定义

位姿 = 位置 + 朝向：

- 位置：$\mathbf{p} = [x, y, z]^T \in \mathbb{R}^3$
- 朝向：旋转矩阵 $R \in SO(3)$（3×3 实矩阵，满足 $R^T R = I,\ \det R = 1$）
- 位姿：$T = \begin{bmatrix} R & \mathbf{p} \\ \mathbf{0} & 1 \end{bmatrix} \in SE(3)$（4×4 齐次变换矩阵）

> [!note] 为什么用矩阵不用"欧拉角三个数"
> 欧拉角（roll/pitch/yaw）直观但有歧义（同一位姿有多种角度组合）且在某些角度会奇异（万向锁）。旋转矩阵无歧义、可直接乘法复合——代价是 9 个数存 3 个自由度。VLA 论文里的动作输出两种都常见（读论文时要能认出来）。

绕 z 轴转 θ 的旋转矩阵（务必亲手推导一次）：

$$R_z(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

### 2. 齐次变换的两大运算（整个机器人学的算术）

**复合（链式法则）**——坐标系接力，矩阵按顺序乘：

$$T_0^2 = T_0^1 \cdot T_1^2$$

（"从系 2 到系 0 的变换 = 从 1 到 0，再从 2 到 1"，就像 `token embedding` 逐层传递）

**求逆**——比一般矩阵求逆便宜得多：

$$T^{-1} = \begin{bmatrix} R^T & -R^T\mathbf{p} \\ \mathbf{0} & 1 \end{bmatrix}$$

### 3. 平面 2 连杆机械臂：FK（正运动学）

两节连杆长 $l_1, l_2$，关节角 $\theta_1$（相对 x 轴）、$\theta_2$（相对第一节连杆）：

$$x = l_1\cos\theta_1 + l_2\cos(\theta_1+\theta_2)$$
$$y = l_1\sin\theta_1 + l_2\sin(\theta_1+\theta_2)$$
$$\phi = \theta_1 + \theta_2 \quad (\text{末端朝向})$$

特征：**给定 $q$ 求 $x$ 永远唯一、只需代入**——这就是 FK。机器人每毫秒都在用它做"关节角→末端在哪"。

### 4. 平面 2 连杆：IK（逆运动学）——反着解，开始有故事了

余弦定理解 $\theta_2$（先解它，因为它只依赖几何）：

$$\cos\theta_2 = \frac{x^2 + y^2 - l_1^2 - l_2^2}{2 l_1 l_2}$$

$$\theta_2 = \pm\arccos(\cdot) \quad \leftarrow \text{两个解：肘上 / 肘下}$$

再解 $\theta_1$（用 atan2 保证象限正确）：

$$\theta_1 = \operatorname{atan2}(y, x) - \operatorname{atan2}\big(l_2\sin\theta_2,\ l_1 + l_2\cos\theta_2\big)$$

三个必须理解的性质：

1. **多解**：$\pm$ 两个解（肘上/肘下），6/7 DOF 臂更多——**IK 不给答案，给候选**，选哪个是策略问题
2. **可达工作空间**：$|l_1 - l_2| \le r \le l_1 + l_2$（$r = \sqrt{x^2+y^2}$）——目标太远或（对于 2 连杆）太近都无解
3. **奇异性（Singularity）**：$\theta_2 = 0$（手臂伸直）时雅可比退化，末端失去一个运动方向——伸直的手臂"最有力但最僵"

### 5. 完整代码：FK + IK 互验（roundtrip 测试）

```python
import numpy as np

def fk(theta1, theta2, l1=1.0, l2=0.8):
    """正运动学：关节角 -> 末端位置。永远唯一解。"""
    x = l1*np.cos(theta1) + l2*np.cos(theta1 + theta2)
    y = l1*np.sin(theta1) + l2*np.sin(theta1 + theta2)
    return np.array([x, y])

def ik(x, y, l1=1.0, l2=0.8, elbow_up=True):
    """逆运动学：末端位置 -> 关节角。两个解，可能无解。"""
    cos_t2 = (x**2 + y**2 - l1**2 - l2**2) / (2*l1*l2)
    if abs(cos_t2) > 1.0:
        raise ValueError(f"目标不可达: 距离 {np.hypot(x,y):.2f} 超出 "
                         f"[{abs(l1-l2):.2f}, {l1+l2:.2f}]")
    sign = 1.0 if elbow_up else -1.0
    theta2 = sign * np.arccos(cos_t2)
    theta1 = np.arctan2(y, x) - np.arctan2(l2*np.sin(theta2),
                                           l1 + l2*np.cos(theta2))
    return theta1, theta2

# roundtrip 测试：q -> FK -> x -> IK -> q'，应该还原（或取另一支）
q = (0.5, -0.9)
x = fk(*q)
q1, q2 = ik(*x, elbow_up=False)
print("原始 q:", q, "| 还原 q':", (q1, q2), "| 末端一致:", np.allclose(fk(q1, q2), x))

# 试一个不可达目标
try:
    ik(3.0, 0.0)   # 总臂长 1.8，够不着 3.0
except ValueError as e:
    print("捕获:", e)
```

> [!important] 读懂这段代码 = 本课达标
> - `fk` 里只有三角函数代入——体会 FK 的"平凡"
> - `ik` 里 `arccos` 前必须检查定义域——体会 IK 的"娇气"（不可达、多解、奇异都在这里冒头）
> - `atan2` 而不是 `arctan`——体会象限问题（`arctan` 只返回 $(-\pi/2, \pi/2)$）

## 与其他概念的关系

- **前置依赖**：[[1.2-机器人系统解剖]]（关节角 $q$ 来自编码器，结构参数 $l_1,l_2$ 来自本体）
- **对比区别**：
  - vs **神经网络拟合 FK/IK**：现代学习方法可以直接用网络学 $q \leftrightarrow x$ 映射（甚至学"像人"的冗余解选择）——但网络输出的解没有解析法的正确性保证，实战中两者混用
  - vs **LLM 的位置编码**：机器人位置是真实的 3D 欧氏空间（有物理约束），LLM 位置是抽象 embedding——**机器人动作必须尊重 SE(3) 几何**，这是 3.2 动作 token 化时要小心的第一个坑
- **后续延伸**：
  - 动作空间选关节坐标还是任务坐标 → [[1.4-动作空间与控制频率]]
